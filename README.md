# selenium-student-registration-automation


## 📌 Project Overview
This project automates an end-to-end **Student Registration Form** using Selenium WebDriver with Python.  
It simulates real user interactions on a web form including input fields, dropdowns, date picker, file upload, and form submission.

---

## ✨ Key Features
- 🔹 **Automated form filling** (text fields, radio buttons, checkboxes)
- 🔹 **Date picker handling** using Selenium Select
- 🔹 **File upload automation**
- 🔹 **Dynamic dropdown selection (State & City)**
- 🔹 **Form submission and validation**
- 🔹 **End-to-end UI workflow automation**

---

## 🛠️ Tech Stack
- **Python**
- **Selenium WebDriver**
- **ChromeDriver**
- **UI Automation Testing**

---

## 🧪 Test Scenario
1. Navigate to DemoQA website  
2. Open Student Registration Form  
3. Fill all required fields  
4. Upload profile image  
5. Select date, state, and city  
6. Submit form  
7. Validate success message
